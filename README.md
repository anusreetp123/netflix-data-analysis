# netflix-data-analysis

## Key Insights
• Movies dominate the Netflix catalog compared to TV Shows.
• Certain countries contribute significantly more content.
• Popular ratings indicate target audience trends.
• Genre diversity reflects wide audience segmentation.

## Conclusion
This analysis of the Netflix dataset provides strategic insights into content distribution, audience
targeting, and catalog trends. The findings help understand platform content strategy and support
data-driven decision-making.
